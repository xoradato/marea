Marea

Sell before it spoils.

A sales copilot for small-scale fish sellers who haggle on WhatsApp. Code does the math. Gemma on AMD GPUs writes the words. The seller decides.

What Marea does04 / 09

Read. Decide. Close.

Read

Rules in code pull product, pounds, offer, zone and day out of the buyer's message.

Decide

DECIDE TÚ flags the deals that need the seller and shows the numbers: sell now or wait.

Close

One click confirms the order, updates the stock on ice and writes the receipt.

The model never sets a price.

Code checks every price the model writes. If one is not in the catalog, Marea falls back to a template and says so.
